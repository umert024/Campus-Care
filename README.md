# CampusFix — updated project

CampusFix now has a violet/indigo visual theme and username-based personal accounts.

## Run it

Open two terminals:

```bash
cd backend
npm start
```

```bash
cd frontend
npm run dev
```

Then open the address printed by Vite (normally `http://localhost:3000`).

## Accounts

- Sign in using a username and password; no email address is needed.
- Create any number of accounts from **Create account**. Each user gets their own signed-in session and role-based workspace.
- Included demo usernames: `alok.admin`, `anil.tech`, `mohan.tech`, `ramesh.faculty`, and `aarav.student`.
- The demo password for each included account is `campus123`.

For this classroom/demo project, user records are stored in memory by the backend while it is running, with a browser-local fallback when the backend is not running. Add a database and password hashing before using it in production.
